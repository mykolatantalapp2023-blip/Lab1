**Тема:** Управління кодом та організація робочого простору в Git

## Опис проєкту

Цей проєкт створено в межах лабораторної роботи №1 з дисципліни "Управління IT-проєктами".  
Мета роботи – опанувати професійні навички роботи з розподіленою системою контролю версій Git, навчитися організовувати структуру проєкту, застосовувати стратегії розгалуження, працювати з віддаленими репозиторіями (GitHub) та впроваджувати процеси спільної розробки через Pull Requests та Code Review.

---

## MVP (Мінімально життєздатний продукт)

Мінімально життєздатний продукт – це веб-сторінка (або набір файлів), яка демонструє базову структуру проєкту:

- index.html – головна сторінка
- styles.css – стилі
- script.js – динамічна поведінка
- .gitignore – ігнорування непотрібних файлів

---

## Інструкція з запуску

1. Клонувати репозиторій:
   git clone https://github.com/mykolatantalapp2023-blip/Lab1.git

2. Перейти в папку проєкту:
   cd Lab1

3. Відкрити index.html у браузері

## Структура проєкту

Lab1/
├── .gitignore          # файли та папки, які Git ігнорує
├── README.md           # опис проєкту

├── styles.css          # стилі
├── script.js           # скрипти

## Використані технології

- Git – контроль версій
- GitHub – віддалений репозиторій
- HTML/CSS/JS – для демонстрації MVP
